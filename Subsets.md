When we wish to emphasise that a [[Sets|Set]] $A$ is a subset of a set $B$ but that $A \neq B$, we write $a \subset B$ and say that $A$ is a proper subset of $B$. For $A \subset B$ to be true, it must be the case that $A \subseteq B$ and there must exist and element $x$ of B that is not an element of $A$.

## References
Discrete Mathematics and Its Applications Sec. 2.1.3 - Kenneth H. Rosen
> "The set $A$ is a *subset* of set $B$, and $B$ is a *superset* of $A$, if and only if every element of $A$ is also an element of $B$. We use the notation $A \subseteq B$ to indicate that $A$ is a subset of the set $B$. If, instead, we want to stress that $B$ is a superset of $A$, we use the equivalent notation $B \supseteq B$. (So, $A \subseteq B$ and $B \supseteq A$ are equivalent statements.)"

> "For every set $S$, $\emptyset \subseteq S$ and $S \subseteq S$."
