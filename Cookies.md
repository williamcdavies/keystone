A cookie is a small block of data created by a web server while a user is browsing a website and placed on the user's computer or other device by the user's web browser. 

Cookies serve useful and sometimes essential functions on the web. They enable web servers to store stateful information on the user's device or to track the user's browsing activity. They can also be used to save information that the user previously entered into form fields.
