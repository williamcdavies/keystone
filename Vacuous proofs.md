Vacuous proofs are [[Proofs]] that demonstrate the validity of the conditional statement $p \rightarrow q$ when $p$ is false. Vacuous proofs are often used to establish special cases of theorems that state that a conditional statement is true for all positive integers.

```
Show that the proposition P(0) is true, where P(n) is "If n > 1, then n^2 > n" and the domain consists of all integers.
```

> [!example]
Note that $P(0)$ is "If $0 > 1$, then $0^2 > 0$." We can show $P(0)$ using a vacuous proof. Indeed, the hypothesis $0 > 1$ is false. This tells use that $P(0)$ is automatically true.
