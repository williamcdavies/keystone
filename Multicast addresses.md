A multicast address is an identifier for a group of hosts that are available to process [[Datagrams]] or frames intended to be multicast for a designated network service. 

## IPv4
The [[Classless inter-domain routing (CIDR)]] notation for this group is `224.0.0.0/4`. The group includes the addresses from `224.0.0.0` to `239.255.255.255`.


| IP multicast address range         | Routable |
|:---------------------------------- |:-------- |
| `244.0.0.0` - `224.0.0.255`        | No       |
| `224.0.1.0` to `224.0.1.255`       | Yes      |
| `224.0.2.0` to `224.0.255.255`     | Yes      |
| `224.1.0.0` to `224.1.255.255`     | No       |
| `224.2.0.0` to `224.2.255.255`     | Yes      |
| `224.3.0.0` to `224.4.255.255`     | Yes      |
| `224.5.0.0` to `224.255.255.255`   | No       |
| `225.0.0.0` to `231.255.255.255`   | No       |
| `232.0.0.0` to `232.255.255.255`   | Yes      |
| `233.0.0.0` to `233.251.255.255`   | Yes      |
| `233.252.0.0` to `233.255.255.255` | Yes      |
| `234.0.0.0` to `234.255.255.255`   | Yes      |
| `235.0.0.0` to `238.255.255.255`   | No       |
| `239.0.0.0` to `239.255.255.255`   | Yes      |
