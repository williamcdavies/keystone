## Style Guide: Python
If anything is not explicitly documented under this style guide refer back to [PEP8](https://peps.python.org/pep-0008/).

### File Headers
File headers should be of the following format:

```python
"""
Filename: <filename>
Author: <author>
Modified: <date>
"""
```
