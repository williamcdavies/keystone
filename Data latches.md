Data latches, or transparent latches, are gated [[Bistable multivibrators]] similar to [[Set-reset latches]]. However, unlike set-reset latches, data latches are implemented with only one logical input $D$ in addition to one enable input $EN$. The output $Q$ of data latches follows input $D$ only when $EN$ enters an active state.
