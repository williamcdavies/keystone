Let $E$ be a simple solid region where $S$ is the boundary surface of $E$ with positive orientation. Let $\vec{F}$ be a vector field whose components have continuous first order [[Partial derivation|Partial derivatives]]. Then,
$$\int{ \int_S{ \vec{F} \cdot d \vec{S} } } = \int{ \int{ \int_E{ \text{ div } \vec{F} \space dV } } }$$
