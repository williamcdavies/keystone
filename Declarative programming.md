Declarative programming is a programming paradigm that expresses the logic of a computation without describing its [[Control flow]].

Many languages that apply this style attempt to eliminate [[Side effects]] by describing what the program must accomplish in terms of the problem domain, rather than describing how to accomplish it as a sequence of the programming language primitives. This is in contrast with [[Imperative programming]], which implements algorithms in explicit steps.
