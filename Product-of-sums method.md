The product-of-sums method for representing the standard expression of a boolean function:

```
Represent (A + B)(A + B + C)(B + C) using the product-of-sums method.
```

> [!example]
> $$\begin{align}
(A + B)(A + B + C)(B + C) &= (A + B + C')(A + B + C)(A + B + C)(A + B + C)(A' + B + C) \\\\
&= (A + B + C')(A + B + C)(A' + B + C)
\end{align}$$
