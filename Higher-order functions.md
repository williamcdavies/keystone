A higher-order function is a function that either takes one ore more functions as arguments or returns a function or function value as a result. All other functions are first-order functions. In the untyped [[Lambda calculus]], all functions are higher-order. In a typed lambda calculus, from which most [[Functional programming]] languages are derived, higher-order functions that take one function as argument at values with types of the form $(\tau_1 \rightarrow \tau_2) \rightarrow \tau_3$.
