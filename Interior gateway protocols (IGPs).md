An interior gateway protocol (IGP) or interior routing protocol is a type of routing protocol used for exchanging routing table information between gateways within an [[Autonomous systems (ASs)|Autonomous system (AS)]]. This routing information can then be used to route [[Network layer]] protocols like [[Internet protocol (IP)]].

Interior gateway protocols can be divided into two categories: [[Distance-vector routing protocols]] and link-state routing protocols. Specific examples of IGPs include [[Open shortest path first (OSPF)]] and [[Routing information protocol (RIP)]].
