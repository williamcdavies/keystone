In data transmission, serial communication is a method of conveying binary digits one at a time using a single conductor. The number of binary digits transferred per second is known as the bit rate. If one binary digits represents one symbol, then the bit rate is the same as the [[Baud rate]].

## Asynchronous Serial Communication
Asynchronous serial communication is a sub-category of serial communication where there is no common clock signal between the transmitter and the receiver.

## Synchronous Serial Communication
Synchronous serial communication is a sub-category of serial communication where there is one common clock signal between the transmitter and the receiver.
