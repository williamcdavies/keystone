Let $S = \{ v_1, \dots , v_p \}$ be a set in $V$. Let $H = \text{ span } \{ v_1, \dots , v_p \}$. If a vector $v_k$ in $S$ is a [[Linear combinations|Linear combination]] of the remaining vectors in $S$, then the set formed from $S$ by removing $v_k$ still spans $H$. If $H \neq \{ 0 \}$, some [[Subsets|Subset]] of $S$ is a basis for $H$.
