Universal generalisation is the [[Rules of inference|Rule of inference]] for quantified statements that states that $\forall xP(x)$ is true, given the premise that $P(c)$ is true for all elements $c$ in the domain. Universal generalisation is used when we show that $\forall xP(x)$ is true by taking an arbitrary element $c$ from the domain and showing that $P(c)$ is true.
