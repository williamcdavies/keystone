Systems of linear equations are collections of two or more linear equations involving the same variables. Such systems may have $0$, $1$, or infinitely many solutions. Systems with $0$ solutions are described as inconsistent systems since there exists no set of values which satisfies the collection of linear equations. Systems with $1$ solution are described as consistent systems since there exists one set of values which satisfies the collection of linear equations. Systems with infinitely many solutions are described as dependent systems since there must exist more variables than independent equations.
