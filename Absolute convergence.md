[[Series|Infinite series]] are said to converge absolutely if the sum of the absolute values of the summands are finite (i.e., $\sum^{ \infty }_{n = 0}{a_n}$ is said to converge absolutely if $\sum^{ \infty }_{n = 0}{ \text{ | } a_n \text{ | } } = L$ for some real number $L$). Similarly, [[Improper integration|Improper integrals]] are said to converge absolutely if the integral of the absolute value of the integrand is finite (i.e., $\int_0^{ \infty }{ \text{ | } f(x) \text{ | } \space dx} = L$).
