[[Sets|Set]] builder notation is a notation method for describing where elements of a set are characterised by stating the property of properties they must have to be members. Set builder notation is used when it is tedious or impossible to list all the elements of a set. For instance, the set $Q^{+}$ of all positive rational numbers can be written as $Q^{+} = \{ x \in \mathbb{R} \mid x = \frac{p}{q} , \text{ for some positive integers } p \text{ and } q \}$.
