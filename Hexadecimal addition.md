1. Convert all hexadecimal digits in each column to corresponding decimal digits.
2. If $\sum_{ \text{ two-value } } \leq 15_{10}$, bring down the corresponding hexadecimal digit.
3. If $\sum_{ \text{ two-value } } > 15_{10}$, bring down the amount that exceeds $16_{10}$ and carry a $1_{10}$ to the next column.
