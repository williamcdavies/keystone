A Bootstrap Loader (or Bootloader) in [[Operating systems]] is a small [[Programs|Program]] that initiates the operating system loading process when a computer is powered on or restarted. Its main job is to locate the operating system kernel and load it into memory.

"Bootstrapping"
- at each stage of "booting", a smaller/simpler program loads and executes the more complicated one of the next stage
