The network layer is layer $3$ of the [[Open systems interconnection (OSI) model]].

The network layer provides the means of transferring variable-length network packets from a source to a destination host via one or more networks. Within the service layer semantics of the OSI model, the network layer responds to service requests from the [[Transport layer]] and issues service requests to the [[Data link layer]].
