Clairaut's theorem states that exchanging the order of [[Partial derivation|Partial derivatives]] of a multivariate function does not change the result if some continuity conditions are satisfied; that is, the second-order partial derivates satisfy the identities
$$\frac{ \partial }{ \partial x_i} ( \frac{ \partial f}{ \partial x_j} ) = \frac{ \partial }{ \partial x_j} ( \frac{ \partial f}{ \partial x_i} )$$
