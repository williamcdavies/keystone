The integral test for convergence is a method used to test [[Series|Infinite series]] of monotonous terms for convergence.

Consider and integer $N$ and a function $f$ defined on the unbounded interval $[N, \infty )$, on which it is monotone decreasing. Then the infinite series
$$\sum^{ \infty }_{n = N}{f(n)}$$

converges to a real number if and only if the improper integral
$$\int_{N}^{ \infty }{f(x) \space dx}$$

is finite. In particular, if the integral diverges, then the series diverges as well.
