Syntax analysis (also known as parsing) involves parsing the token sequence to identify the syntactic structure of the program. This phase typically builds a parse tree, which replaces the linear sequence of tokens with a tree structure built according to the rules of [[Formal grammars|Formal grammar]] which define the language's syntax. The parse tree if often analysed, augmented, and transformed by later phases in the [[Compilation|Compiler]].
