A cache is a hardware or software component that stores data so that future request for that data can be served faster. A cache hit occurs when the requested data can be found in a cache, while a cache miss occurs when it cannot.

To be cost-effective, caches must be relatively small. Nevertheless, caches are effective in many areas of computing because typical computer applications access data with a high degree of [[Locality of reference]].
