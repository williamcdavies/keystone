The linear span of a set $S$ of vectors, denoted $\text{ span } (S)$, is defined as the set of all [[Linear combinations]] of the vectors in $S$. For example, two linearly independent vectors span a plane. The linear span can be characterised either as the intersection of all linear subspaces that contain $S$, or as the smallest subspace containing $S$. The linear span of a set of vectors is therefore a vector space itself.
