A network switch is a multiport network bridge that uses MAC addresses to forward data at the [[Data link layer]] (layer $2$) of the [[Open systems interconnection (OSI) model]]. Some switches can also forward data at the [[Network layer]] (layer $3$) by additionally incorporating routing functionality. Such switches are commonly known as layer-$3$ switches or multilayer switches

## Managed Switches
Managed switches have one or more methods to modify the operation of the switch. Common management methods include: a command-line interface, an embedded [[Simple network management protocol (SNMP)]], or a web interface. 

Managed switches use STP (Spanning Tree Protocol) to prevent loops and MAC address tables to forward frames to the correct destination.
