The sum-of-products method for representing the standard expression of a boolean system: 

```
Represent AB + ABC + BC using the sum-of-products method.
```

> [!example]
> $$\begin{align}
AB + ABC + BC &= AB(C+C') + ABC + (A+A')BC \\\\
&= ABC + ABC' + ABC + ABC + A'BC \\\\
&= ABC' + ABC + A'BC
\end{align}$$
