If some function $f$ is twice-differentiable at a critical point $P$ then:
- If $f''(P) < 0$, then $f$ has a local maximum at $P$.
- If $f''(P) > 0$, then $f$ has a local minimum at $P$.
- If $f''(P) = 0$, then the second derivative test is inclusive.

In the last case, [[Taylor's theorem]] may sometimes be used to determine the behaviour of $f$ near $P$ using higher order derivatives.
