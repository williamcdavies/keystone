The ESPRESSO heuristic logic minimiser, or ESPRESSO Algorithm, is a computer program that uses heuristic algorithms to efficiently reduce the complexity of combinational logic circuits. When compared to [[Karnaugh maps]] and the [[Quine-McCluskey method]], [[The Espresso heuristic logic minimiser is a more efficient way to compute the minimal expression of a boolean function]].
