A Request for Comments (RFC) is a publication in a series from the principal technical development and standards-setting bodies for the Internet, most prominently the Internet Engineering Task Force (IETF).

## Requirement Levels
- Required: all systems must implement
- Recommended: all systems should implement
- Elective: not required nor recommended
- Limited Use: used in certain situations, such as experimental
- Not Recommended: systems should not implement
