Classless Inter-Domain Routing (CIDR) is a method for allocating [[Internet protocol (IP)]] addresses for IP routing.

## CIDR Blocks
IPv4 CIDR blocks are identified using a syntax similar to that of IPv4 addresses: a dotted-decimal address, following by a slash, then a number from $0$ to $32$, i.e., `a.b.c.d/n`.
