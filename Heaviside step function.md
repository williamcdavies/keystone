The Heaviside step function is a step function, the value of which is zero for negative arguments and one for positive arguments. Different conventions for concerning the value $h(0)$ are in use.

## Formulation 
Taking the convention that $h(0) = 1$, the Heaviside function may be defined as:
$$h(x) = 
\begin{cases}
1, x \geq 0 \\ \space \\
0, x < 0
\end{cases}$$
