The parity method for error detection uses a parity bit to determine whether an odd number of errors has occurred within a group of bits. Depending on a systems parity (either even parity or odd parity), the parity bit will be used to bring the total number of high output bits to be an even or odd value. So when a data block is received, if the total number of high output bits does not match the expected parity of the system, an error must have occurred.
