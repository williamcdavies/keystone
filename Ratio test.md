The ratio test is a test for the convergence of [[Series|Infinite series]] where each term is a real or complex number and $a_n$ is nonzero when $n$ is sufficiently large.

The usual form of the test makes use of the limit
$$L = \lim_{n \to \infty }{ \left| \frac{a_{n + 1}}{a_n} \right| }$$

The ratio test states:
- If $L < 1$ then the series converges absolutely.
- If $L > 1$ then the series diverges.
- If $L = 1$ or if the limit fails to exist, then the test is inconclusive as there exists both convergent and divergent series that satisfy this case.
