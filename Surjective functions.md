A function $f$ is said to be surjective, or onto, if for each element in $B$, there is at least one element in $A$ such that $f(a) = b$ where $a$ is an arbitrary element in $A$ and $b$ is an element in $B$.

---
## References
Discrete Mathematics and Its Applications Sec. 2.3.2 - Kenneth H. Rosen
> "A function $f$ from $A$ to $B$ is called *onto*, or a *surjection*, if and only if for every element $b \in B$ there is an element $a \in A$ with $f(a) = b$. A function $f$ is called *surjective* if it is onto."
