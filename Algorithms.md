An algorithm is a finite sequence of rigorous instructions, typically used to solve a class of specific problems or to perform computations. 

An algorithm can be seen as a recipe for a computer to follow. Algorithms take an input and produce an output. The output will be the answer to a question regarding the input.

## Important Requirements for Algorithms
1. Algorithms should be deterministic. Given the same input, the algorithm should always produce the same output.
2. The algorithm should be correct for any arbitrary valid input.
