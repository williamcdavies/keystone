Existential generalisation is the [[Rules of inference|Rule of inference]] for quantified statements that is used to conclude that $\exists xP(x)$ is true when a particular element $c$ with $P(c)$ true is known. That is, if we know one element $c$ in the domain for which $P(c)$ is true, then we know that $\exists xP(x)$ is true.
