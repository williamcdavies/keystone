IP is the [[Network layer]] communications protocol in the [[Internet protocol suite]] for relaying [[Datagrams]] across network boundaries. Its routing function enables internetworking, and essential establishes the Internet.

IP has the task of delivering [[Network packets]] from the source host to the destination host solely based on the IP addresses in the packet [[Headers]]. For this purpose, IP defines packet structures that encapsulate the data to be delivered. It also defines addressing methods that are used to label the [[Datagrams|Datagram]] with source and destination information. IP was the connectionless datagram service in the original Transmission Control Program, which was complemented by a connection-oriented service that became the basis for the [[Transmission control protocol (TCP)]]. The [[Internet protocol suite]] is therefore often referred to as TCP/IP.
