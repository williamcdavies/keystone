Reduced instruction set computation (RISC) is an [[Instruction set architecture]] designed to simplify the individual instructions given to the computer to accomplish tasks. Compared to [[Complex instruction set computation]] (CISC), RISC might require additional instructions in order to accomplish similar tasks. The goal of RISC is to offset the need to process additional instructions by increasing the speed of each instruction through [[Instruction pipelining]].
