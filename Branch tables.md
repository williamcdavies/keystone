A branch table or jump table is a method of transferring program control to another part of the program using a table of branch or jump instructions. The branch table constructions is commonly used when programming in assembly language but may also generated by compilers when implemented optimised switch statements.

## Advantages
- Compact code structure (despite repeated branch opcodes)
- Reduced source statements (versus repetitive `if` statements)
- Reduced requirements to test return codes individually (if used at call site to determine subsequent program flow)
- Algorithmic and code efficiency (data need only be encoded once and branch table code is usually compact), and the potential to attain high data compression ratios.

## Disadvantages
- Extra level of indirection, which incurs a usually small performance hit
- Restrictions in some programming languages, although there are usually alternative ways of implementing the basic concept of multiway branching.
